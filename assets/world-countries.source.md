# Country outline data

Source: [Natural Earth, 1:10m administrative countries](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/). These replace the original 1:110m outlines with more detailed borders, coastlines, and islands.

Downloaded from the [Natural Earth vector repository](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson).

Natural Earth data is public domain. The locally stored `world-countries.geojson` is used to render the map without a third-party tile service or runtime network dependency. City coordinates are approximate, authored separately in the location JSON files.
